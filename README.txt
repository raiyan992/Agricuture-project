Kisan Mitra - Agriculture Website (HTML + CSS + JavaScript)

Kaise chalayein:
1. Folder ko VS Code mein kholein.
2. index.html par right click -> Open with Live Server.

Files:
index.html          - page structure
css/style.css       - saari styling aur responsive design
js/translations.js  - Hindi/English text
js/data.js          - crops aur Crop Doctor ka data
js/app.js           - saari functionality
images/             - apni photos yahan rakhein

Abhi baaki: SQL file, login/register, dashboard, admin panel.
